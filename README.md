🎬 Movie Sales Analysis Dashboard | Power BI
📌 Project Overview
The Movie Sales Analysis Dashboard is an interactive Power BI project designed to analyze movie sales performance using various business intelligence techniques. The dashboard helps stakeholders understand revenue trends, customer behavior, movie performance, and sales distribution through visually appealing and interactive reports.

This project demonstrates the complete data analysis workflow, including data cleaning, transformation, modeling, DAX calculations, visualization, and dashboard design.

🎯 Business Problem
Movie production companies and distributors generate large volumes of sales data from different regions, genres, and customers. Analyzing this data manually is difficult and time-consuming.

The objective of this project is to build an interactive dashboard that enables decision-makers to:

Monitor sales performance
Identify top-performing movies
Analyze customer purchasing patterns
Compare revenue across genres and regions
Make data-driven business decisions
🎯 Project Objectives
Analyze overall movie sales performance.
Identify top-selling movies.
Compare revenue across different genres.
Analyze sales by region and customer.
Monitor monthly sales trends.
Provide interactive filtering for detailed analysis.
Build an easy-to-understand business dashboard.
